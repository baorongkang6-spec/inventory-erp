## 4. 远程与日常运维流程

### 4.1 生产日常更新（推荐）

**方式 A：管理员右键运行 `update.bat`**（已内置：停服务 → 备份 → `git pull` → `uv sync` → `collectstatic` → `migrate` → 启服务）

**方式 B：PowerShell 分步（落后多提交或 `update.bat` 自身要更新时更稳）**

```powershell
cd C:\inventory-erp
.\nssm stop InventoryERP
.\backup.bat nopause
git pull
uv sync
uv run python manage.py collectstatic --noinput
uv run python manage.py migrate
.\nssm start InventoryERP
.\nssm status InventoryERP
```

验收清单：

1. `.\nssm status InventoryERP` → `SERVICE_RUNNING`
2. `uv run python manage.py showmigrations | Select-String "\[ \]"` → **无输出**（无未应用迁移）
3. 外网域名能登录进首页（非 500）
4. 抽查：总览四列勾稽、一两个往来余额表、最近改过的功能点

注意：

- PowerShell 用 `.\nssm` / `.\backup.bat`，不要写 `call backup.bat`。
- **带数据迁移必先备份**；`migrate` 失败时 `update.bat` **不会**重启服务，修好后再 `nssm start`。
- 若生产 git 落后很多且旧 `update.bat` 会在 pull 中途自替换，改用上面「分步」流程（见 DEV_NOTES 运维踩坑）。

### 4.2 备份与恢复意识

- 每日：跑 `backup.bat`（或计划任务），**再拷一份到移动硬盘/异地**。
- 用 SQLite backup API（`scripts/backup_db.py`），优于直接拷正在写入的 `db.sqlite3`。
- 定期做一次「停服务 → 换备份库 → 启服务 → 登录核对」恢复演练。

### 4.3 远程访问与安全底线

- 外网只走花生壳 **HTTPS**；生产 `DJANGO_PRODUCTION=1`、`DJANGO_DEBUG=0`、强 `SECRET_KEY`、`ALLOWED_HOSTS` / `CSRF_TRUSTED_ORIGINS` 含花生壳域名。
- 登录有失败锁定（见 `.env.example` 的 `LOGIN_*`）；演示弱密码仅开发用。
- **禁止**把真实 `SECRET_KEY`、账号密码写进 Git / Obsidian / 聊天记录。

### 4.4 本机开发（Mac）最短路径

```bash
cd /Users/baorongkang/work/inventory-erp
uv sync
uv run python manage.py migrate
uv run python manage.py runserver
# 改完必测
uv run python manage.py test
# 推送：git push（同时推 GitHub + Gitee）
```

操作手册改完后重生成 docx/pdf（命令见原 Obsidian「已验证流程」或 DEV_NOTES）。

## 5. 业务与账务口径（运维常被问到）

完整操作见 `docs/操作手册.md`。运维/报表核对时记住：

| 主题 | 口径 |
|------|------|
| 库存计价 | 移动加权平均；**禁止负库存** |
| 往来产生 | **发票**产生应收/应付；入库/出库本身不挂往来（借调除外） |
| 收/付款 | 登记自动写银行存款日记账；核销手工勾发票 |
| 应收票据 | 收票抵应收 **不消耗票面**；背书/兑付/贴现才「票出去」 |
| 无票背书预付 | 挂采购订单 → 应付余额表按订单供应商体现；到票先撤销再背书冲发票 |
| 未勾发票的收票/收款 | 客户应收余额表记 **预收**（本期收回↑，期末可为负）；勾发票后不重复计 |
| 金额显示 | 一律两位小数（`round_money`）；SQLite `SUM` 后必须量化，否则会出现长尾 0 |
| 报表日期 | 未选手动区间时：上月早于启用日则默认 **启用日~今天** |
| 总览应收票据 | 与「应收票据余额表」同口径（按业务日，不用 `created_at`） |

开发节奏（接续改代码时）：**服务层守账务一致性 → 视图 `block_reason` → 模板 `can_xxx` → 测试 → 手册 → 提交推送**。

## 6. 常见排障

| 现象 | 优先排查 |
|------|----------|
| 外网打不开 / 证书异常 | 花生壳隧道、HTTPS、本机 Waitress 是否在听 8000、NSSM 服务状态 |
| 登录 500 / CSRF | `ALLOWED_HOSTS`、`CSRF_TRUSTED_ORIGINS` 是否含当前域名；是否仍 `DEBUG=1` |
| migrate 锁库 / 失败 | 是否先 `nssm stop`；是否先备份；看迁移报错后**不要**强行删库 |
| 期初页/总览日期不对 | `ERP_OPENING_DATE`；NSSM 环境变量是否盖住 `.env` |
| 应收余额「少一截收款」 | 是否未勾销售发票的收票——新口径应进「收票预收」；旧生产未更新则先 `update.bat` |
| 金额一长串 0 | 确认已部署含 `round_money` 的版本（2026-08-19 附近提交） |
| git pull 后服务起不来 | 看 `migrate` 是否失败；看 `logs`【路径以现场为准】；`nssm status` |
| 本机测不过 | `uv run python manage.py test`；勿在生产机改代码直接试验 |
